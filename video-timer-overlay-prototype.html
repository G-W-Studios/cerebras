// Speed-demo video system — prototype

A cleaner timer, an unmistakable finish, and fast-forward you can't miss.

Today's overlay is a boxed white number and a small "×5" chip — both easy to lose against busy screen recordings. This template drops the box, adds a real completion moment, and makes sped-up footage obvious even from a single freeze-frame. Everything below renders live in this page; toggle the controls to preview every variant before exporting frames.

01 — Transparent timer

  • Both fonts use tabular figures (font-variant-numeric: tabular-nums) so digits never reflow the layout as seconds tick — this was likely the main reason the old version used a fixed-width white pill.
  • Sometype Mono is the closer brand default (it's already the system's "metrics" typeface), but Manrope Light reads as more editorial for polished hero placements. Ship both; pick per video.
  • Removing the background chip costs legibility on busy footage, so a calibrated soft shadow replaces it — dark shadow under the white variant, light glow under the black variant. It reads as "no background" in a screenshot but stays readable over any b-roll.
  • Export as ProRes 4444 (true alpha) — a plain screen recording won't carry transparency. Fastest path: render this page's timer state at each second as a PNG sequence (headless Chrome, transparent <body>), then ffmpeg -i frame_%04d.png -c:v prores_ks -profile:v 4 -pix_fmt yuva444p10le timer.mov. Say the word and I'll wire up that render script.

02 — Done transition

  • Sequence: digits blur/scale down under a fast orange wipe → a filled orange checkmark draws in → "DONE" pops with a spring ease → after a beat it settles smaller with the elapsed time underneath, so the win registers before the number does.
  • The checkmark is the one deliberate use of orange in the whole overlay — consistent with the one-accent-per-moment rule — which is exactly what makes it read as a clear state change rather than decoration.

03 — Fast-forward

  • Three simultaneous, redundant cues so it survives a scrub, a freeze-frame, or a muted autoplay: a motion-blur ghost trail behind the digits, a jittering scan wobble on the numbers themselves, and a bordered speed chip with looping chevrons instead of a static "×5" label.
  • The chip flashes solid orange for one frame on every speed step-up (2×→5×→10×), so viewers clock the change even mid-scrub.
