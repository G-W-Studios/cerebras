Colored editorial category labels and neutral metadata tags — the small mono pills used across cards, articles and the newsroom.

```jsx
<Label category="blog">Blog</Label>
<Label category="news">News</Label>
<Label category="press-release">Press Release</Label>
<Tag tone="orange">1,000 tok/s</Tag>
```

`Label` categories each map to a fixed accent (blog→peach, news→lilac, press-release→teal, event→green, the rest→ink). `Tag` tones: `neutral` / `dark` / `orange` / `outline`.
