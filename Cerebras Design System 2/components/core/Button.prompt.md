Primary Cerebras call-to-action — a mono, uppercase label on a sharp 2px-corner surface; use the orange `primary` for the main action and `dark`/`outline` for secondary ones.

```jsx
<Button variant="primary" icon="arrow-right">Get started</Button>
<Button variant="dark">Read the docs</Button>
<Button variant="outline" size="sm">Learn more</Button>
<IconButton icon="search" variant="dark" />
```

Variants: `primary` (orange), `dark` (ink), `light` (cream), `outline`, `ghost`. Sizes: `sm` / `md` / `lg`. Pass `icon` + `iconPosition` for a glyph, `href` to render as a link. `IconButton` is the square icon-only form.
